# Task: Implement OpenPencil Design Base for Web & Mobile

## Description
Implement the complete visual design base designed in OpenPencil across both the Web client (Next.js 15 Clean Architecture) and Mobile client (Kotlin Compose Multiplatform). The design prioritizes zero friction ("1-Tap" actions, fewer steps, instant feedback), high-contrast financial typography, live parallel P2P rates, and dedicated views for Auth, Wallet, FX Transfer, Smart Drafts, Monthly Budgets, Financial Goals, Recurring Payments, and Lending.

## Tasks
- [ ] Task 1: Web Foundation & Auth Screen (split hero layout, P2P badge, Google/Apple buttons, main currency selector)
- [ ] Task 2: Web Master Dashboard & Navigation (sidebar with P2P ticker, topbar with ⌘K search, KPI cards, accounts, drafts card with 1-Tap approval, and recent transactions table)
- [ ] Task 3: Web FX Transfer & Drafts Drawers/Modals (1-click FX modal with frozen rate countdown and 1-click bulk drafts drawer)
- [ ] Task 4: Web Presupuestos & Metas Modules (budget manager with safe daily pace and alerts, goals manager with dark analytics banner, and modals)
- [ ] Task 5: Web Recurring Payments & Lending Modules (scheduled payments with reschedule modal, active loans and amortization simulator)
- [ ] Task 6: Mobile Compose Design Base (top status bar with P2P rate, dark balance card, 1-Tap action buttons, accounts row, recent activity)
- [ ] Task 7: Mobile 1-Tap Sheets & Modals (1-Tap numeric keypad, drafts review sheet, loan collection sheet, budgets and recurring tabs)
- [ ] Task 8: End-to-End Build & Verification (Web vitest/build, Mobile gradle checks, clean commit)
