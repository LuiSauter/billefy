# Financial backup and reset
Implement downloadable financial-data backup and a separate reset action that preserves the account, profile, and preferences.
The backup must cover the user's financial records; reset must remove those records so the user can start again.

## Specs
1. The user requested: "En la page de settings, faltaria agregar la opcion de poder borrar todos los datos financieros y poder hacer un backup para descargar, porqu e eliminar? bueno para que el usuario pueda volver a empezar a registrar datos financieros nuevamente..."
2. The user confirmed: "Sí, solo datos financieros" — erase financial records while retaining the account, profile, and preferences, separately from account deletion.
