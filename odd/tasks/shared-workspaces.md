# Feature: Shared Workspaces (Espacios Compartidos / Together)

Full end-to-end implementation of the Shared Workspaces module for Billefy across backend (.NET modular monolith) and web frontend (Next.js + shadcn/ui), matching the 11 UX/UI screen designs in `docs/redesign/` without mock or test seed data.

## Scope & Core Principles
- **No Test/Dummy Data Injections (Rule 16 in AGENTS.md):** The database and UI must operate strictly with authentic user records and real APIs. No seeders or dummy test rows.
- **Strict Migration-Driven Changes (Rule 17 in AGENTS.md):** Database schema changes must only be executed through official Entity Framework Core migrations (`dotnet ef migrations add <Name>`).
- **Money & Ledger Integrity (Rules 1, 3, 4, 5 in AGENTS.md):**
  - Amounts use `decimal` in C# and `numeric(20,6)` in Postgres.
  - Personal account transactions remain immutable in `Ledger`. A shared expense records the full bank debit in the payer's personal account, while `Workspaces` tracks the split shares (`personal_share` vs `counterparty_receivable`).
  - Settlements reconcile balances between workspace members without duplicating revenue or expenses.
- **Privacy & Resource Authorization:**
  - Workspace members only access data explicitly scoped to the workspace. Personal accounts, total net worth, and private transactions of members remain strictly confidential.
- **Design System & shadcn Standardization (Rule 18 in AGENTS.md):**
  - Adherence to project design tokens and `@/shared/ui/*` shadcn components (`ResponsiveDrawer`, `FormField`, `MoneyInput`, `Input`, `Button`, `SegmentedControl`, `Select`, etc.).
